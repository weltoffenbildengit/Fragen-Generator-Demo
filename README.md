# Demo: Fragen-Generator DHSpez M4

Diese Demo zeigt einen statischen Fragen-Generator fuer Critical Incidents und Planungsaufgaben zur Pruefungsvorbereitung.

## Demo starten

`index.html` im Browser oeffnen.

## Enthalten

- CI-Fragen mit Musterloesungen
- PLA-Fragen mit Musterloesungen
- Freischaltung der Musterloesung erst nach eigener Antwort
- Demo-Daten direkt in `app.js`

## Nicht enthalten

- keine lokalen PDF-Quellen
- keine geschuetzten Skriptunterlagen
- keine internen Arbeitsdateien

Die offiziellen Beispielserien sind in der Demo verlinkt.
